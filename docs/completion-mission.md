## Intended-host connected-LAN decision

No connected-LAN Stage A plan is accepted for the intended workstation. The only contemplated feature write is one machine-wide WTSEnableChildSessions(true) from an already elevated physical console, followed by exact restoration to the reported original False. ChildStream would leave ordinary Remote Desktop policy, existing firewall rules, native Sunshine/VDD and shared network settings unchanged. Those direct-write limits do not contain a newly created TermService listener: the historical firewall assessment has 20 potentially permissive and six unknown allow rules. Service/listener monitoring after the call cannot prevent a transient connected-LAN exposure. A local temporary block rule has not been designed, tested against effective policy and internal guest paths, or approved; do not treat it as an existing mitigation.

Because the current parent logon predates feature enablement, Microsoft's automatic-child-authentication exception applies to that logon. A first-setup fresh sign-in may be needed before a password-free child connection can be validated. Signing out closes applications in that Windows logon session and cannot be presumed safe for protected work. It is not a normal ChildStream launch, reconnect or Moonlight pairing step. No sign-out is proposed on the intended workstation under the current scope boundary.

**Authorization plan:** request no intended-host mutation now. The next actionable approval is an exact-source v6 Stage A run on an independent, no-NIC Windows 11 Pro console or independent no-NIC VM after its read-only plan passes and the operator verifies offline sign-in and recovery. That approval would cover only one journaled feature enablement from original False, one operator-controlled fresh parent sign-in if required, WTS verification, and exact restoration to False. Stop on error 1168, unexpected TermService or RDP listener, ambiguous child identity, journal drift or incomplete restoration; preserve the isolated target and journal for reviewed recovery. Stage B child creation requires another approval. Reconsider the intended workstation only after an independently validated connected-LAN RDP containment and a noninterfering parent-authentication path exist; any later request must name its exact changes and rollback evidence.
