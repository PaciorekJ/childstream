## Remaining uncertainties and blockers

1. **Current host state is No-Go.** The completed offline rehearsal proved physical severance during that window, but Docker/WSL remained active and the addressed Tailscale path was unattributed. The workstation was reconnected afterward. Stage A cannot be authorized from that historical capture.
2. A separately approved, operator-controlled workload pause requires each workload owner to review the private exact inventory and shutdown matrix, application-specific data flush/backup and resumption steps. A graceful stop alone does not establish durability. The pause must remain effective after fresh logon. If it cannot, use a separately approved disposable switch-disconnected Windows 11 VM rather than forcing the physical host gate.
3. A separately approved Tailscale disconnect, physical disconnection and second local observer must establish and maintain external severance. The read-only v5 `plan-boundary` must then return an exact hash only when `External`, `GuestPath` and `RdpExposure` all pass. A Tailscale tunnel retaining any address or route remains `Unknown` even after `tailscale down`; no interface-name whitelist is permitted. The exact original Tailscale configuration and post-reconnect state must be compared privately.
4. Exact plan-hash approval, child-feature mutation, fresh console sign-out/logon and any reviewed recovery remain separate operator gates. Offline sign-in with a physical-console recovery administrator has not been demonstrated; it must be verified before a mutating Stage A logon cycle. The original host configuration, Sunshine and VDD must stay untouched. `TermService`, RDP listeners, feature state and journal must be checked before reconnection.
5. The first live Stage A result must establish WTS behavior after fresh logon. It does not itself establish a second interactive desktop. The Stage B viewer lifetime and same-v5-journal transition are implemented in source but remain live-unverified and separately unauthorized. Child connection, independent-desktop interaction, Sunshine, controllers/audio, games, installer live rollback and real-device acceptance remain unrun.
6. This Codex process is not elevated and cannot certify current Docker/WSL workload state. The private workload inventories are snapshots, not current outage-safety proof. Owners must confirm data preservation, active transfers, deployments, replication, pending writes and stateful remote dependencies before the larger Stage A/B outage. No container health or restart-policy observation establishes that safety.
