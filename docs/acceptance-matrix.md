Raw host inventories, plan hashes, credentials and pairing data remain in restricted local evidence, never in this repository. The prior published baseline is `06f2a0eedb99b4ac2a153eea7a54fb8ac4cc8457`; its [Windows CI run 38810684221](https://github.com/PaciorekJ/childstream/actions/runs/38810684221) passed. The v6 strict-isolation increment requires its own exact-SHA CI result before a live test. The permanent [scope boundary](scope-boundary.md) blocks shared-workstation Stage A/B through workload or network interruption. None of the offline rows proves that the intended gaming session works.
