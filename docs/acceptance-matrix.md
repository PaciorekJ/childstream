The source now connects first-run setup, protected installation, child agent, optional explicitly approved LAN mode, Sunshine pairing and Steam/game requests. The unsigned ZIP is uninstalled, controller routing stays disabled, and no real WTS/GPU/Moonlight result exists. The next decisive evidence is an approved [independent Windows test target](stage-ab-physical-window.md), starting with the read-only strict-isolation plan and then a separately approved Stage A Windows API result. A positive WTS result alone does not establish an independent desktop. The shared workstation remains blocked until a coexistence design preserves unrelated work and contains ordinary RDP exposure without interrupting services.
